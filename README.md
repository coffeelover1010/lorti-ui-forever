# Lorti UI Forever

![Lorti action buttons in game](docs/images/action-buttons.png)

- Dark borders and glossy buttons for WoW Forever.
- Supports Blizzard action buttons and Bartender4 action and pet buttons.
- Styles supported unit frames, minimap borders and buff icons.
- Separate options for windows, bags, tooltips and more.
- Open **Settings > AddOns > Lorti UI Forever**, then `/reload` after changes.
- Bartender keeps its own text settings. Masque takes priority for button skins.
- Beta: some frames are not supported; full combat and taint testing is ongoing.

Install the [latest release](https://github.com/coffeelover1010/lorti-ui-forever/releases) in `Interface/AddOns/LortiUIForever`.
